# P5 · 国内模型专区

`/zh-CN/domestic-models/` 覆盖 DeepSeek、通义千问、智谱 GLM、月之暗面 Kimi、MiniMax 和豆包 / 火山方舟。简中首页与 sitemap 增加入口。每个厂商卡片保留模型详情、官方价格入口、人民币输入/输出/缓存单价、支付方式和核实日期字段。

`src/data/domestic_models.json` 的国内人民币价格与支付字段目前为空。云实例代理阻止直接访问相关厂商定价页面，现有仓库快照也没有足够的人民币支付资料。可访问的厂商官方 GitHub README 没有这些数据。页面显示「暂无」，不从美元费率推断官方人民币定价或付款方式。

独立的人民币折算组件使用仓库已有的官方美元价格记录。选择 DeepSeek 高峰费率和海外 API，然后按用户填写的汇率折算每百万输入、输出 Token 成本。折算结果用于预算估算。引用源和原核实日期随每条美元费率展示。

## 验证

- `npm run build`、`npx tsc --noEmit`、`npm run lint`。
- `node --test tests/domestic-pricing.test.mjs` 验证有效汇率和拒绝缺失、无效汇率。
- 云端浏览器以桌面和移动视口、浅色和深色主题验证切换海外模型、人民币折算和未知字段。
- 静态导出检查验证专区 canonical、sitemap、原 P4 路径以及 P0 和 P3 导出合同。

此阶段无需新密钥或 D1 迁移。待数据维护者可访问厂商官方定价与结算页面后，可在数据文件内独立补齐缺失字段并记录来源与日期。正式服务器仍使用现有静态构建流程。
