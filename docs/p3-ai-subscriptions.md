# P3 · AI 会员对比

`src/data/ai_subscriptions.json` 包含八个产品和七组精选对比。新增英文与简中栏目首页、产品页和对比页。栏目提供用途筛选和三个问题的套餐推荐，导航、Deals 个人订阅筛选与开发接入页提供入口。价格展示保留官方来源和核实日期，页面列出用量限额、模型、功能、用途、免费档与大陆可用性字段。未确认的信息显示「暂无」。

已标价字段来自仓库 `official_deals.json` 中带官方来源与核实日期的记录。当前云实例代理阻止直接访问这些厂商域，因此这次没有刷新核实日期。Microsoft Copilot、豆包和通义保留官方入口，套餐名和价格为空。人民币价格、限额、免费档、功能及国内可用性缺乏足够官方记录时为空。用途标签是站点编辑分类，用于筛选，并非官方承诺。没有加入未经证实的推荐佣金链接。推荐选择器按匹配用途和预算中最低的已记录月费排序，对要求大陆可用且无法验证时不推荐。

## 验证

- `npm run build`、`npx tsc --noEmit`、`npm run lint`。
- `node scripts/verify-subscriptions.mjs out` 核对产品和套餐来源、静态页面、sitemap、唯一两种语言的 hreflang 和 FAQPage。
- 云端浏览器验证用途筛选、正常推荐、大陆可用性未知时的提示、精选对比与官方来源链接。验收截图覆盖桌面与移动端的浅色、深色主题。

此阶段无需新密钥或 D1 迁移。使用现有静态构建和部署方式。后续由数据维护者直接查阅厂商官网补充空字段，不从相近的 API 价格或第三方报价推算个人套餐价格。
