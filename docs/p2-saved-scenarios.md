# P2 · 模拟场景

首页默认显示请求量、输入和输出 Token、三个场景预设及预计月成本。`SimulatorDeck` 展开后提供缓存率、批处理、长上下文、缓存写入摊销、供应商和路由选择。现有估算器、路由导出和排行榜继续可用。

`src/lib/scenarios.ts` 编解码请求量、Token、缓存、批处理、长上下文、复用次数、供应商过滤、比较基线、路由策略和展开状态。旧版 `reqs/in/out/cache/batch/long` 链接继续可读，输入检查会回退无效值及限制范围。最近场景本地保存，按最近保存排序，每个浏览器最多 5 条。robots.txt 覆盖原分享参数及新链接中的 `reqs`。

## 验证

- `node --test tests/scenarios.test.mjs` 验证全参数往返、旧版链接、无效值与最近场景上限。
- 云端浏览器在桌面和移动端的浅色、深色主题中验证保存、剪贴板分享、打开链接恢复高级选项以及最近场景的一键恢复。
- `npm run build`、`npx tsc --noEmit`、`npm run lint`。en 和 zh-CN 文案完整，zh-TW、ja、ko、es 使用英文新增文案。

此阶段无需新密钥或 D1 迁移。正式服务器使用原静态站点构建方式。浏览器禁用存储或禁止剪贴板时会显示对应状态。
